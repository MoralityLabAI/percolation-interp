Percolation analysis for neural influence graphs

A small NumPy/SciPy Python library for directed source-to-output connectivity profiles, graph nulls and component-selection hypotheses. Bring your own attribution edges, including exported Goodfire VPD or SAE graphs.

Minimal API

pip install 'git+https://github.com/MoralityLabAI/percolation-interp'

from percinterp import from_attribution_arrays, profile, rank_entry
import numpy as np

data = from_attribution_arrays(
    ['token:0', 'layer0.up:8', 'metric:output'],
    [0, 1, 2],
    np.array([0, 1]), np.array([1, 2]),
    np.array([0.8, -0.4]),
)
p = profile(data.graph, rank_entry(data.graph.weight,
                                  data.graph.edge_layer('dst')))
print(p.p_span)

The example weights are synthetic. Signed edge values and external node IDs are retained; percolation uses their absolute magnitudes. Read the full API guide.

Goodfire compatibility

A dedicated CI job installs Goodfire’s actual param-decomp-formats package from a pinned public commit, checks the ComponentKey(site, component_idx).encoded() contract, and round-trips those IDs through the graph importer. The native identifier test uses synthetic edges. A measured VPD demonstration requires one exported direct-attribution edge table with source run, metric, aggregation method and topological stages.

Scientific evidence and distribution

PercInterp’s graph statistics are useful as diagnostics and as candidates for causal tests. E03 found a small-model component selection benefit; E04 did not establish Qwen transfer; E06/E07 show substantial local-degree confounds; E10’s causal selector comparison awaits saved VPD inference inputs.

The wheel and source distribution build successfully in distribution CI. The package is not yet published to PyPI. Release guide.
